# ViT learning modules

This folder contains the step-by-step Vision Transformer building blocks.

File guide:

```text
config.py                  Shared ViT config values
module.py                  Tiny custom Module base class
neuron.py                  Single neuron versions
layer.py                   Layer made from many neurons
mlp.py                     MLP and ReLU
layer_norm.py              Custom and PyTorch LayerNorm
patch_embedding.py         Image to patch-token embeddings
layer_norm_demo.py         LayerNorm math demo
transformer_block_demo.py  PyTorch transformer-block demo
scratch_vit.py             Older scratch ViT notes/code
```
